# 使い方

## 起動すると

画面の右下に、本体ウィンドウが出ます。通知領域（タスクトレイ）にも Wezen のアイコンが出ます。

- 本体ウィンドウは、ヘッダーやグラフをつかんで動かせます
- 縁をドラッグすると、大きさを変えられます
- 位置と大きさは、次の起動でも同じになります。大きさはレイアウトごとに覚えます

## 本体ウィンドウ

| 項目 | グラフ | 左上の文字 |
|---|---|---|
| CPU | 使用率 | 使用率 |
| Memory | 使用率 | 使用率、使用量 / 上限 |
| I/O | 読み取り + その他（R+O）、書き込み（W） | 毎秒の量 |
| GPU | 使用率 | 使用率、専用メモリの使用量 / 全体 |
| Disk | 読み取り（R）、書き込み（W） | 毎秒の量 |
| Network | 受信（R）、送信（S） | 毎秒の量 |

- 読み取りと受信は青、書き込みと送信は橙で描きます
- 橙の小さな数字は、表示している範囲の最大値（ピーク）です
  - 山が左上の文字に重なるときは、右上に「最大」と付けて出します

ヘッダーのボタン:

- ピン: 常に手前に表示するかを切り替えます
- 歯車: 設定を開きます
- ×: 本体ウィンドウを隠します。Wezen は終了しません

帯のレイアウトにはヘッダーがありません。設定は、通知領域のアイコンから開きます。

## 通知領域のアイコン

- 左クリック: 本体ウィンドウの表示と非表示を切り替えます
- 右クリック: メニューを出します（表示、設定、終了）

## グラフの見え方

設定の「グラフ」で変えられます。プレビューに、元のデータと実際に描く線が重ねて出ます。

| 設定 | 内容 |
|---|---|
| ならしの強さ | 前後の値を同じ重みで平均し、とがった山を左右対称のなだらかな山にします |
| 右端の扱い | 「すぐ出す」は、新しい山が右端で半分だけ立ち上がり、値がそろうにつれて形が整います。「遅らせて出す」は、山が最後まで左右対称ですが、グラフが数秒遅れます |
| スクロール | 「なめらか」は、更新の合間もグラフが少しずつ流れます |
| 通信量の目盛り | I/O、Disk、Network のグラフを、線形か対数で描きます |

左上の数字は、どの設定でも遅れずに今の値を出します。

更新間隔を途中で変えても、それまでのグラフは消えません。画面上の点の間隔も変わりません。

## 値の取り方

| 項目 | 取り出し元 |
|---|---|
| CPU | `GetSystemTimes`（Process Explorer と同じ考え方） |
| Memory | `GlobalMemoryStatusEx` のコミット済みの量 |
| I/O | システム全体の I/O の累計（`NtQuerySystemInformation`） |
| GPU | 性能カウンターの `GPU Engine` と `GPU Adapter Memory`、全体の量は DXGI |
| Disk | 物理ドライブごとの `IOCTL_DISK_PERFORMANCE` |
| Network | `GetIfTable2`。物理アダプターだけを数えます |

- Memory は、物理メモリとページファイル（スワップ領域）を合わせた量です
  - タスクマネージャーの「コミット済み」と同じ値で、上限は物理メモリとページファイルの合計です
- GPU が複数あるときは、専用メモリが最も多いものを出します
  - 設定の「全般」で選び直せます
- Network は、VPN などの仮想アダプターを数えません
  - 同じ通信を、仮想と物理の両方で 2 回数えないためです

## 終了する

通知領域のアイコンの右クリックメニューか、設定画面の左下の「Wezen を終了」から終了します。本体ウィンドウや設定画面を閉じても、Wezen は動き続けます。
